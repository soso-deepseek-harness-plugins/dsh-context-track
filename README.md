# 上下文链路追踪

宿主插件。把一次 agent 会话收成可展开的树：轮次、模型步骤、工具、子会话，以及会话命名、上下文压缩和检索。顶部是轮次条和可折叠的上下文摘要带；点开节点可看该次调用的输入、输出和元数据。

插件只记录调用。模型步骤的正文留在宿主会话日志里，点开时按序号重放；只有日志里没有的旁路短字段，才追加到插件自己的增量文件。

## 怎么打开

三处入口名称都是「上下文链路追踪」，都看当前会话；浏览器和 Desktop 共用这一套界面。

- **会话页签**：当前会话打开时出现。页签里收起输入框和宽度手柄，审批、提问和计划卡仍留在原位。
- **右侧栏**：引导页里打开，面板停在当前会话旁边。
- **左侧栏**：面板列表里的一项。点开后，中间栏显示同一份面板，并跟随外壳保留的主会话。

## 面板骨架

自上而下四段：header、轮次条、上下文摘要带、树与详情。

- **header**：当前轮次名和状态、正在看的节点、总消耗、总耗时、摘要带开关，以及「更多」菜单（全部展开、全部收起、恢复默认宽度）。总消耗和总耗时取自当前轮次的报告。
- **轮次条**：横向胶囊，每枚一个轮次。第一行是状态点、`turn N`，以及「N 个步骤 · N 个工具」；第二行是带标签的总耗时和总消耗，缺失时显示 `-`，所以不用点开也能比较各轮花费。轮次之间的会话命名、上下文压缩和检索是窄标签，点开直接进入该节点。选中的胶囊会滚入视野，轮次超过 6 个时右侧显示 `轮次 N / 总数`。悬停只高亮，点击才固定；聚焦后左右方向键切换轮次。

摘要带默认只占一行：构成条、图例和展开按钮。展开后是构成、耗时、旁路三块自适应网格，最高约 40vh（单列档 60vh），自己滚动，不推走树和详情。

- **构成**：按 token 占比堆叠的条，图例默认 4 项，其余折成 `+N`。分类有系统提示、用户消息、工具定义、工具结果、注入内容、技能注入和历史回复，按大小排，工具结果和工具定义跟在用户消息之后。点色块或图例会在详情里定位到对应的输入消息；压缩在构成条上留一道缝，点击定位到该压缩节点。统计行给出输入、输出、思考 token 和缓存命中率。工具定义、注入内容、技能注入的分类行可以展开明细：搜索、按大小或名称排序、最大 5 条加剩余个数；工具定义另显示定义开销。
- **耗时**：总耗时（进行中的轮次带「进行中」）、模型等待、模型思考、首个响应；用户中途输入的首响应单列。
- **旁路**：压缩腾出的 token 和摘要调用花费（已在轮次总消耗里），以及子会话的另计消耗；会话命名不计入轮次总消耗。

## 树

```
turn 1
├─ step 1   deepseek-flash
│  ├─ llm_call 1
│  ├─ llm_call 2
│  ├─ read_file
│  └─ subagent
│     ├─ 检索
│     └─ turn 1
├─ 会话命名
├─ 上下文压缩
└─ step 2
```

行首是状态点、节点图标和名称；步骤、尝试和工具另外显示耗时，步骤和尝试右侧是输入 → 输出的 token。当前节点高亮。折叠的轮次给步骤数，折叠的步骤给调用数和工具数。同一 step 里并行的工具是兄弟节点，按 `tool/call` 排序；检索挂在触发它的工具或 step 下面。对不上工具结果的子会话挂在该轮末尾，标成未关联。只有 `origin` 为 `subagent` 的子会话会嵌进这棵树，它的轮次直接接在工具下面；`mode: external` 没有本地日志，不能展开。父工具在子会话还有未结束的轮次时保持进行中。

尚未结束的轮次默认展开，其余收起。展开状态留在组件里，不写进投影。树内耗时和 token 两列按树自身宽度先收耗时、再收 token。

## 详情

详情有「阅读」和「JSON」两个视图，切走再切回会保留各自的折叠和滚动位置。顶部是面包屑、复制整份 JSON 和关闭，窄档另有返回。点开节点：

- **模型步骤 / llm_call**：provider、model、温度、推理强度、输出上限、窗口序号、状态，以及重试原因和退避。输入消息按角色和分类显示，带 token 估算、来源、工具名和调用 id；系统提示默认折叠，长正文先折 8 行，可展开全文，每张卡片都能单独「在 JSON 中打开」。输出分成思考和回答，思考单列并淡显；工具调用按名称和参数展示。同一步里的失败重试各自算一次 llm_call，步骤默认打开最后一次尝试。
- **工具**：参数、结果，以及「在树中展开」子会话。
- **会话命名**：系统提示、消息、路由和采纳的标题；还没得到名称时输入仍完整显示。
- **上下文压缩**：阅读视图是摘要；JSON 视图按输入和输出分开，输入含被压缩的消息、末尾指令和配置，输出含摘要、原始输出、用量和错误，失败时状态为失败。
- **检索**：先给触发这次调用的工具名和参数（或步骤、llm_call 及其输出），再给查询词和去掉密钥的请求体。

长正文按 Markdown 渲染；整体是 JSON 的块直接给可折叠的 JSON，键、字符串、数字、布尔和 null 分色，对象和数组按深度折叠，超长字符串先折成预览，也能对字符串手动「按 JSON 解析」。输出 token 用 `token=`（精确）或 `token≈`（估算）标注；缩写数字点一下复制完整十进制。缺失的数值显示 `-`，未结算显示「尚未结算」，还没产生的输出显示「尚未看到」。

## 布局与键盘

宽档 ≥960px，树和详情并排，默认 38% / 62%。中间分隔线命中区 8px、视觉线 1px，可拖动、双击复位，聚焦后方向键按 24px 调整；树最小 240px，详情最小 320px。紧凑档 640–959px 仍然并排。窄于 640px 只保留一个主滚动区：树占满，详情从右侧整页滑入，用返回按钮或 `Esc` 关闭，关闭后焦点回到触发的树行或轮次胶囊，滚动位置不变。宽档关掉详情后树占满，再点树行恢复。摘要带展开状态和分隔比例记在 `localStorage`（前缀 `dsh-context-track:`），读取失败回默认值。

- `↑` / `↓`：在可见的树行之间移动
- `→` / `←`：展开 / 收起当前行；轮次条聚焦时切换轮次
- `Enter`：固定当前选中；在轮次条上固定该轮次
- `Esc`：关闭详情或覆盖层

首帧先按窄档渲染，测得面板宽度后再切换档位，避免闪一帧宽布局。界面文案提供中文和英文，样式只使用宿主的 `--dsw-alias-*` 主题变量。

## 要求

- Node.js `^22.19.0 || >=24`
- pnpm `>=11`（本仓库钉在 `pnpm@11.28.5`）
- 宿主 `>=0.2.0-0 <0.3.0`
- Host 同时提供 `sessionProjections` 和 `sessions` 时，插件才会激活

再次打开已结束的会话，还需要宿主的会话读取能力。

## 安装与开发

装进 profile：

```bash
dsh plugin --profile <profile> add dsh-context-track
```

本仓库：

```bash
pnpm install
pnpm test        # Vitest，用例在 tests/
pnpm run build   # Host → lib/，客户端 → lib/client/index.js
pnpm run clean   # 删掉 lib/
```

客户端产物是 `window.__ModuleLoader__.load` 工厂。编译、发布和源码联调见 [docs/publish-install.md](docs/publish-install.md)。协议 Apache-2.0。
